# ASCII-Art-Generator
A simple ASCII Art Generator made in Python3 <br>
Made with the help of this guide: https://robertheaton.com/2018/06/12/programming-projects-for-advanced-beginners-ascii-art/ (I know it sounds like I just copied from a guide but the guide just prompts you) <br>

__Download:__
- Go to the [releases](https://github.com/Alex-M-2013/ASCII-Art-Generator/releases/latest) section
- Download and run the .exe file
- Enter the path to your image
